# Feature Suggestions

## Uso Diário

- **Playback sincronizado** — tocar o áudio na tela de transcrição com highlight do trecho atual. Transforma o app de "leitor" para "revisor real"
- **Search global funcional** — busca semântica (ChromaDB já existe) + full-text em todas transcrições. Botão já existe na sidebar, não faz nada
- **Export** — PDF / TXT / SRT (legendas). Saída real do trabalho

## Produtividade

- **Templates de resumo** — usuário configura prompts por tipo ("standup", "entrevista", "call de vendas"). Backend já tem LLM, só falta UI
- **Edição inline do transcript** — corrigir erros de transcrição antes de exportar/enviar
- **Integrações com 1 clique** — backend já tem Obsidian/Notion/Slack/Email wired, falta UI exposta na tela de transcrição

## Inteligência

- **Ações da reunião** ← próxima feature
  Extrair action items automaticamente após transcrição. Pipeline: LLM + prompt estruturado → lista de tarefas com responsável + prazo (quando mencionado)
- **Identificação de speakers por voz** — treinar perfil de voz do usuário para não precisar configurar mic/monitor manualmente
